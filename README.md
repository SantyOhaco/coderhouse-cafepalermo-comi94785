# Proyecto Cafetería Coderhouse - Palermo

Proyecto de optimización SEO y servidores para el módulo de Desarrollo Web. Una propuesta de cafetería de especialidad y espacio de coworking diseñada por y para la comunidad tech en Palermo, Buenos Aires.

## 🚀 Sitio en Vivo
Podés ver la web funcionando e implementada en producción en el siguiente enlace:
👉 **[coderhousecafe-palermo.netlify.app](https://netlify.app)**

## 🛠️ Optimizaciones Realizadas
* **SEO On-Page & Técnico:** Inclusión de etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<article>`), evitando contenedores genéricos y estructurando títulos con una jerarquía correcta (un solo `<h1>` por página).
* **Etiquetas Meta:** Incorporación de descripciones únicas y palabras clave específicas por página.
* **SEO Local:** Configuración de metadatos geográficos para Palermo, Buenos Aires (`geo.region`, `geo.placename`).
* **Accesibilidad (a11y):** Inclusión de textos alternativos (`alt`) detallados y descriptivos en todas las imágenes.
* **Optimización de Archivos:** Renombrado de archivos a minúsculas y formatos adecuados para servidores web (como `index.html`).
